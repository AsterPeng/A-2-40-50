## 复现与核验

在个人目录下进入 `src/week-03/`，使用 Node.js 22+ 和 pnpm：

```text
pnpm install --frozen-lockfile
pnpm check
pnpm build
```

该历史阶段的测试数量为4个；测试仅覆盖本地实现与匿名合成输入。

历史执行命令按原文保留；文档中迁移后的内联文件路径以“彭定星”个人目录为基准。计划中的文件不因本次归档而补造。

整理前本地 Excel 的成果物路径通过上方映射定位，交付版 Excel 已同步本次新路径；仓库中的整理日期不是历史开发执行日期。HTTP 202、离线测试与本机 Mock 均不代表真实 A-5 持久化验收。
