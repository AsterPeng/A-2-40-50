# 输入约定（草案）

本线入口为上游已规范化的匿名合成 `TrackPoint`。输入来自夹具或外部边界时均先视为 `unknown`；TypeScript 类型断言不能代替运行时验证。本线验证结构与测量值，不实施上游规范化。

| 字段                    | 输入约定                                               | 本线责任                 |
| ----------------------- | ------------------------------------------------------ | ------------------------ |
| `timestamp`             | 带毫秒的 UTC ISO 8601，例如 `2026-10-27T08:30:12.345Z` | 验证格式，不转换时区     |
| `flightNumber`          | 字符串                                                 | 验证结构，不清洗航班号   |
| `position.latitudeDeg`  | WGS84 十进制度字符串，范围 `[-90, 90]`                 | 验证语法和精度安全的边界 |
| `position.longitudeDeg` | WGS84 十进制度字符串，范围 `[-180, 180]`               | 验证语法和精度安全的边界 |
| `altitudeFt`            | 英尺的十进制字符串                                     | 验证语法，保留原始字符   |
| `groundSpeedKt`         | 节的十进制字符串                                       | 验证语法，保留原始字符   |
| `source`                | 字符串；夹具使用 `synthetic`                           | 验证结构，不访问供应商   |

请求草案为 `{ "schemaVersion": "1.0", "tracks": [TrackPoint] }`，批次暂定 1 至 1000 条。字段缺失或额外字段均拒绝。测量值验证之后仍保存输入字符串，不能通过数值转换重新生成字符串。尾零、指数和负零的具体合法语法及边界比较算法在第 2 周 ADR 中明确，并由第 3 周自动测试验证。

初始领域类型见 `src/domain/track.ts`，端口草案见 `src/ports/a5-track-client.ts`。这些类型不是运行时验证器，不能把现阶段的类型检查当作输入验收。
