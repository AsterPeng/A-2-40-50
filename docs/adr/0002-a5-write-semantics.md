# ADR 0002: A-5 写入、重试与幂等语义

状态：第 2 周开发设计，待正式 A-5 契约确认。需求：RQ-A-2-50。实际记录日期：2026-10-27。

## 请求与端口

所有写入经 `A5TrackClient`。`postOne` 将单条航迹包装成 `TrackBatch`，`postBatch` 处理 1 至 1000 条；两者在发出网络请求前调用同一个运行时验证器。请求草案为 `POST /v1/tracks`、`Content-Type: application/json`、必填 `Idempotency-Key`。四个测量值始终是 JSON 字符串。公开端口不使用 `any`，解析网络内容以 `unknown` 开始。

`src/ports/a5-track-client.ts` 已在第 2 周补充 `invalid-request`、`unexpected-status` 和可选 HTTP 状态；仍是类型草案，尚无运行时验证和 HTTP 实现。本地无效批次的 `attempts` 为 0，且不得发送网络请求；未知 HTTP 状态不得落入 202 成功分支。正式契约差异应同步端口、OpenAPI、Mock、测试和追踪矩阵。

## 幂等与请求体

验证通过后按固定字段顺序序列化一次请求体，在同一调用的所有尝试中复用完全相同的字节。开发草案的幂等键由请求体 SHA-256 摘要生成，前缀 `a2-` 加 base64url 摘要，长度小于 128；相同语义字段和数组顺序产生同一请求体与键。测量值的字符表示是语义的一部分，因此 `12500.00` 与 `12500` 不应被视作同一请求体。绝不因超时、网络错误或 409 随机更换键补写。真实 A-5 的键规则及窗口仍属 [A5-Q07](../requirements/a5-open-questions.md)。

## 202 响应

HTTP 202 仅表示草案中的**接收确认**，不是数据库持久化证明。响应须有非空 `requestId`、非负整数 `acceptedCount` 和 `rejected` 数组。每个拒绝项的 `index` 为 `[0, N-1]` 中唯一整数，`code` 与 `message` 为字符串，且 `acceptedCount + rejected.length = N`。`rejected` 为空且计数为 N 时为全接收；非空时为部分拒绝（可接受数为零）。结构、计数或索引非法的 202 为永久 `invalid-response`，不得记为成功或重试。

## 失败与重试

| 情况                     | 草案处理                                                 |
| ------------------------ | -------------------------------------------------------- |
| 本地验证失败             | 不发送请求；返回明确的输入错误，具体端口类型待实现时同步 |
| 400、409                 | 永久失败；409 不更换幂等键                               |
| 429                      | 有限重试；合法 `Retry-After` 优先，否则退避              |
| 503、网络错误            | 有限重试并退避                                           |
| 超时                     | 结果为未确认；默认不重试，可配置有限重试且同键同体       |
| 调用方取消               | 立即停止，包含退避等待期间；不重试                       |
| 非法 202、其他 HTTP 状态 | 不当作成功；其他状态默认不重试，待正式契约确认           |

默认上限草案为总计 3 次尝试（包括第一次），指数退避上限 30 秒；等待、时钟、网络与随机源可注入。`Retry-After` 支持非负秒数和 HTTP-date，按注入时钟计算；无效值回退到退避，过长值受配置上限约束。调用方取消信号与每次请求超时信号组合；取消优先于同一时刻的超时分类。每次尝试完成后清理计时器和监听器，重试耗尽后保留最后错误与总尝试数。超时后的“未确认”不能推断 A-5 未写入。

失败记录只包含本地分类、HTTP 状态（若有）、尝试数、批次条数、是否未确认和有限长度的诊断标识；不得含认证头、token、完整请求体、完整外部响应或原始航迹。外部错误 `message` 不直接写日志。正式认证方式仍属 A5-Q02，未授权时不连接真实服务。
