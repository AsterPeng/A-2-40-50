# A-2-40-50

需求：RQ-A-2-40 / RQ-A-2-50。

独立的航迹十进制精度保护与 A-5 写入客户端项目。范围和十周安排见根目录的 [项目简报](CURRENT_LINE_PROJECT_BRIEF.md)。

## 当前状态

第 1 周只确认需求、输入约定、边界与验收方向。`src/domain` 和 `src/ports` 是待第 2 周复核的类型与端口草案；精度校验、HTTP 客户端和 Mock 尚未实现。测试 ID 已在[追踪矩阵](docs/requirements/traceability.md)中规划，功能测试尚未执行。HTTP 202 或本地 Mock 结果均不能证明真实 A-5 落库。

## 工程检查

要求 Node.js 22+ 和 pnpm。安装依赖后运行 `pnpm check`；源代码变更后运行 `pnpm build`。当前 `test` 命令允许无测试通过，仅用于第 1 周工程骨架检查；不能把该结果作为需求验收。

项目不抓取上游数据、不处理供应商授权或范围过滤、不做字段/单位/时间规范化与去重，也不直连 A-5 数据库。后续测试只使用匿名合成的已规范化 `TrackPoint`。
